advISO Validation Guide
========================

This repository contains the source files for the [advISO Validation Guide](https://adviso-validation-guide.readthedocs.io/en/latest), which provides guidance on performing validation / verification of bioinformatics pipelines within an ISO 15189 context.

## Building locally

```bash
cd docs
pip install -r requirements.txt
make html
```

The built site will be in `docs/_build/html/`. Open `index.html` to preview.
